# Quick Start Guide

## Get Started in 3 Steps

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Open in Browser
Navigate to `http://localhost:5173`

## That's It! 🎉

The API key is already configured in the `.env` file.

## Try These Features

1. **Search for a city**: Type "London" or "New York"
2. **Search by country**: Type "France" to see major French cities
3. **Toggle theme**: Click the 🌙/☀️ button in the top-right
4. **View tabs**: Switch between Current, Historical, and Marine weather

## Build for Production

```bash
npm run build
npm run preview
```
